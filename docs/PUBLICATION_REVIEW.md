# Source publication review (2026-10-08)

Publishing this modified source as `muscle_gpu` under GPLv3 is consistent with the permission granted for MUSCLE5, subject to retaining the license and notices and identifying modifications. This is a source-distribution review, not an upstream certification or a guarantee about every possible jurisdiction or third-party right.

Evidence: the supplied `muscle/LICENSE` is the unmodified GPLv3 text; the [current upstream LICENSE](https://github.com/rcedgar/muscle/blob/main/LICENSE) agrees. The [original paper](https://doi.org/10.1038/s41467-022-34630-w), [full text](https://pmc.ncbi.nlm.nih.gov/articles/PMC9664440/), explicitly identifies GPLv3 in Code availability. The version-specific source and paper take precedence over legacy web pages describing earlier MUSCLE versions as public domain.

[GPLv3 sections4–6](https://opensource.org/license/GPL-3.0) permit modified source distribution while requiring retention of notices, prominent modification/date statements, GPL coverage of the combined work, and corresponding-source provisions for binaries. Root LICENSE and NOTICE.md, original source notices and build scripts are retained. PHYLIP-derived protdist.cpp/repredict.cpp have their own permissive notice; it remains in those files and is reproduced in THIRD_PARTY_NOTICES.md. No restrictive alternative license is added.

The repository is an independent derived implementation from a supplied archive without Git history. It must not claim to be an official MUSCLE release, a historically traceable GitHub fork of a known commit, or an author-endorsed/certified implementation. `muscle_gpu` distinguishes the modified executable. README/CITATION.cff cite Edgar2022 and link upstream. A GitHub-native Fork operation is a provenance convenience, not a license requirement; a separately created attributed repository is permitted by the license.

The public source export excludes article PDFs, server credentials/addresses, connection scripts, private operational logs, build products and local toolchains. Bundled upstream test examples remain identified as upstream examples, not newly authored datasets. Numerical/equality and performance claims are bounded by the documented test cases. The failed60-sequence EACluster reproducibility case is retained, and no universal speedup, biological-equivalence proof or global-first claim is made. Future binaries must ship appropriate third-party notices and matching complete source/build material; do not redistribute the CUDA toolkit itself as part of this source release.

GitHub [browser uploads](https://docs.github.com/en/repositories/working-with-files/managing-large-files/about-large-files-on-github) have a25MiB per-file limit, and ordinary Git blocks files above100MiB. All code files are small; the supplied27MiB RdRp mega archive requires Git/connector upload or a separately hosted asset. Upload actual source directories, not just a compressed opaque project bundle, so code review and CPU CI remain usable.

For the initial GitHub source tree the optional 27MiB `rdrp.mega.gz` structure example is omitted with `--omit-large-example`. It is not required to build or run the amino-acid CUDA implementation or the recorded RdRp FASTA tests; all source code and needed fixtures remain. The original archive is preserved locally. Upstream provides the example at [test_data/rdrp](https://github.com/rcedgar/muscle/tree/main/test_data/rdrp); the received-file identity is retained in the R0 provenance manifest. No model/toolkit binaries are bundled.
